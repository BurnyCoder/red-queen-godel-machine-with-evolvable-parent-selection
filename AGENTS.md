# Research workflow

Use the current repository, its pinned uv environment and the operating assumptions in [the prospective registration](reports/preregistration.md). Read the [source audit](reports/state-of-the-art-review.md) and [run matrix](reports/planned-runs.md) when changing search behavior. Record a dated amendment before confirming any pilot repair that changes scientific settings.

Develop against the normal rqgm-study CLI. Keep scoring on the trusted side. Preserve the independence of the training, validation, pilot evaluation and sealed test groups. Run the tests and regenerate every table and figure from result files. Maintain the report, study-specific methodological review, dashboard and experiment histories. Include all attempted arms and disclose incomplete outcomes. See [operating instructions](docs/usage.md).
